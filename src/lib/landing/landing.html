Agents

Your agent runs
the campaign.

Hedwig is an MCP server. Add it once to Claude Code or Codex, sign in, choose what the assistant may touch, then ask in plain words. And since the code is yours, the same agent can change Hedwig itself.

1

Add the server

$ claude mcp add --transport http hedwig %ORIGIN%/mcp
# then type /mcp in a session to sign in
$ codex mcp add hedwig --url %ORIGIN%/mcp
codex mcp login hedwig
Self-hosting? Use your own address, ending in /mcp.
2

Sign in, pick permissions

Your browser opens Hedwig's sign-in. You choose one workspace and what the assistant may do. Launching a campaign and sending a reply are separate permissions; untick them and it can only read and draft.
3

Ask

  • Pause the roasters campaign, add these 200 contacts, show me step 2 for the first one.
  • Who replied interested this week? Draft answers, I'll send them.
  • Compare this month with last: replies per step and per mailbox.
  • Which mailbox bounces most? Drop its daily limit to 20.
What it does

Everything a cold
email tool needs.

And nothing you pay for per seat. Six things it does every day, with the actual numbers it uses.

Your mailboxes

No relay

Any provider with IMAP and SMTP connects with the mailbox password; the servers are found from the domain's MX record. Microsoft 365 connects with Microsoft's own sign-in.

Passwords and tokens are encrypted at rest with AES-256-GCM. SPF, DKIM and DMARC are checked daily, with the exact record to add.

SPFDKIMDMARC

Sequences

12 steps

Import a CSV or Excel file of any size, map columns to variables, dedupe against the campaign and your suppression list.

Write up to twelve steps with {{firstName|there}} variables and fallbacks. Follow-ups land in the same thread. Preview with real rows, send yourself a test.

Pace

Never a burst

A sending window in the campaign's timezone. A daily limit per campaign and per mailbox, shared across campaigns. New mailboxes start at 10 a day, +5 a week.

00091724

30 sends, 09:00–17:00, spread with jitter

Replies

Every 2 min

Every inbox is read every two minutes. A reply stops the sequence. A bounce stops it and suppresses the address. Out-of-office notes are recognized and, by default, ignored.

A mailbox pauses itself when bounces reach 5% of a week's sends.

Reply agents

Drafts, never sends

Set up your own agents: who you are, your tone, what never to promise. Each campaign picks one. It labels every reply and writes a draft for the interested ones, the meetings and the questions.

CloserLabel + draft
We roast in small batches in Portland. Short and friendly. Never promise a delivery date.

You edit the draft in the Inbox and press send. An agent never sends by itself.

Honest numbers

Counted, not guessed

Sent, opens, replies, bounces and opportunities per day, step, mailbox and campaign. Every number on screen is a count of real events.

Opens from mail scanners are discounted, so an open rate isn't just your send count. People who open more often than you emailed them get flagged curious.
